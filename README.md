# AI Smart Classroom Proctoring System

An advanced, secure, and gamified AI interface that tracks student engagement and posture in real-time while integrating Google Gemini AI for continuous personalized motivational advice.

## ⚠️ Important Note for Evaluation
When you run the application, it will ask for a Name and a Google Gemini API Key:
1. Enter your **Name** and press Enter.
2. In the **API Key input box, simply press Enter (leave it blank)** to automatically launch the application in **Simulation Mode**. No actual API Key is required to test the core features!

## Features
- **Glassmorphism HUD UI:** Futuristic overlay display for cross-platform video processing.
- **Attention Tracking:** Iris center distance calculation for distraction alerts.
- **Ergonomics Monitoring:** Real-time spine alignment and slouch counting.
- **Google Gemini AI Integration:** Dispatches student metrics every 15 seconds to fetch custom-tailored feedback.
- **Privacy & Security First:** Prompt-driven initialization using getpass for absolute API Key safety.

## How to Run Locally
Run the deployment script to prepare the virtual environment and execute the core application:
bash deploy.sh
